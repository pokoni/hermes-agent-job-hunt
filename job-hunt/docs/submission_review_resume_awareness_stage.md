# Submission Review Resume Awareness Stage

This stage does not change the frozen pipeline. It strengthens the existing `submission-review-gate` skill so it understands resume artifacts generated by `resume-tailor`.

## Why this stage exists

After `outputs/resumes/` and tracker resume linkage were added, `submission-review-gate` should no longer report resume/CV files as missing when:

```text
outputs/resumes/<job_basename>_resume_manifest.json
outputs/resumes/<job_basename>_resume_ja.md
outputs/resumes/<job_basename>_cv_ja.md
```

exist.

## Frozen pipeline remains unchanged

```text
job-normalizer
→ job-fit-scorer
→ resume-tailor
→ jp-application-writer
→ application-tracker
→ browser-apply-assistant
→ submission-review-gate
→ live-submission-adapter
```

## Required behavior

`submission-review-gate` must:

1. read `outputs/resumes/<job_basename>_resume_manifest.json`,
2. copy `resume_version`, `resume_file`, and `cv_file` into `submission_decision.json`,
3. avoid reporting resume/CV as missing if all resume artifact files exist,
4. keep browser/platform blockers visible,
5. keep the human approval boundary explicit.

## Recommended command

Inside Hermes:

```text
/submission-review-gate Create the final submission review package for data/jobs/03_regnio_ml_iot_engineer_fukuoka_2026.json using available artifacts under outputs/, including outputs/resumes/03_regnio_ml_iot_engineer_fukuoka_2026_resume_manifest.json. Write outputs/logs/03_regnio_ml_iot_engineer_fukuoka_2026_submission_review.md and outputs/logs/03_regnio_ml_iot_engineer_fukuoka_2026_submission_decision.json. The decision JSON must include top-level keys status, decision, resume_version, resume_file, cv_file, resume_manifest, human_review_required, explicit_human_approval_required, and live_submission_allowed. Do not submit by default. Stop before final submission. Explicit human approval is required before any submit action.
```
