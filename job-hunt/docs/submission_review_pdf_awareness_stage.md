# Submission Review PDF Awareness Stage

This stage does not change the frozen pipeline. It strengthens the existing `submission-review-gate` so it understands PDF resume/CV export artifacts generated by `resume-tailor`.

## Current project stage

The project is in the **submission document export completion stage**.

The pipeline can now generate and track:

- Markdown resume/CV artifacts,
- DOCX resume/CV artifacts,
- PDF resume/CV artifacts.

## Frozen pipeline

```text
job-normalizer
→ job-fit-scorer
→ resume-tailor
→ jp-application-writer
→ application-tracker
→ browser-apply-assistant
→ submission-review-gate
→ live-submission-adapter
```

There is no `submission-session-orchestrator`.

## Why this stage exists

After tracker PDF linkage, `submission-review-gate` should be able to review the actual `.pdf` files that may be used for application upload.

It should distinguish between:

- Markdown resume/CV artifacts,
- DOCX resume/CV artifacts,
- PDF resume/CV artifacts,
- missing files,
- present files that still require human visual review.

## Required behavior

When this file exists:

```text
outputs/resumes/<job_basename>_pdf_export_manifest.json
```

`submission-review-gate` must record these fields in:

```text
outputs/logs/<job_basename>_submission_decision.json
```

Required fields:

```json
{
  "resume_pdf_file": "",
  "cv_pdf_file": "",
  "pdf_export_manifest": "",
  "pdf_human_visual_review_required": true
}
```

The review Markdown must include:

```md
## PDF Export Artifacts
```
