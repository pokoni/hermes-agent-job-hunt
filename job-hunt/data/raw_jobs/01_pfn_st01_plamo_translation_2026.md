# PLaMo翻訳サービスの機能改善・新機能開発

## Source snapshot
- PFN 2026 夏期インターンの短期コーステーマ ST01。
- Preferred Networks が開発する「PLaMo翻訳」の既存機能改善と新機能の提案・設計・開発を扱う。
- 主な想定は、LLM や AI を使って既存機能を改善したり、新しい価値のある機能として成立させたりすること。
- 参考サービス URL として `https://translate.preferredai.jp/` が示されている。
- コミュニケーション言語は日本語。
- 短期コースの実施期間は 2026-08-07〜2026-08-28 または 2026-08-31〜2026-09-18。

## Visible requirements
- 基本的なコーディング能力
- Web サービスまたはプロダクト開発の経験

## Preferred / plus factors
- React / TypeScript を使ったフロントエンド開発経験
- バックエンド API の開発経験
- Python を使った開発力
- LLM / AI 関連の開発経験
- Public Cloud を使ったサービス構築・運用経験

## General internship eligibility visible on official internship page
- インターン実施時点で 18 歳以上の学生であること
- 日本語または英語で主体的にコミュニケーションできること
- 平日に会社の求めに応じて大手町オフィスに来社できること
- 日本国内でインターン活動が可能な法的資格を持つこと
- 開発に使える個人所有 PC を用意できること

## Missing or hidden information
- 報酬額は、この取得範囲では確認していない
- 実際の担当内容は選考過程で相談の上で最終決定
